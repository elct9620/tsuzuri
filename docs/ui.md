# Tsuzuri 介面設計

這份文件記錄各畫面的配置，介面的改動先改這裡再實作。元件與配色以 daisyUI 為基底，表中「元件」欄寫 daisyUI 元件名稱；其他內容見下表。

| 要找 | 看 |
|---|---|
| 畫面的意圖與資料 | `docs/design.md` 第 2、11 章 |
| 畫面的行為 | `.spec/behavior/` |
| 圖示與快速鍵 | `docs/architecture.md` 4.8 |

## 1 骨架

```
  ┌──────────────┬────────────────────────────────────────────────────┐
  │ 資源清單     │ lecture [開啟 ▾] [轉錄] [翻譯] [辨識] [匯出 ▾] [設定] [⌨] │
  │ （第 3 節）  ├───────────────────────────────────────────────────────────┤
  │              │ 字幕編輯（第 4 節）                                       │
  │              │   只有段落清單會捲動                                      │
  └──────────────┴───────────────────────────────────────────────────────────┘
```

| 區域 | 內容 | 元件 |
|---|---|---|
| 工具列 | 專案名稱與專案層級的動作 | navbar |
| 專案名稱 | 點一下就地改名 | input-ghost |
| 改名提示 | 停留時框線、✎ 與 tooltip | input、tooltip |
| 視窗標題 | 專案名稱與 Tsuzuri | — |
| 開啟 ▾ | 目錄、SRT、最近的專案 | dropdown、menu |
| 轉錄、翻譯 | 開啟第 5、6 節的任務 | btn |
| 辨識 | 開啟 5.2 的任務 | btn |
| 匯出 ▾ | 見第 8 節 | dropdown、menu |
| 設定 | 開啟第 7 節的設定 | btn |
| ⌨ | 開啟 1.4 的快速鍵一覽 | btn-square |
| 整頁 | 左清單，右工具列與編輯 | drawer |
| ☰ | 蓋上或固定清單，見 1.7.1 | btn-square |
| 通知 | 右下角堆疊，見 1.3 | toast、alert |

字幕編輯是唯一的主畫面，任務與設定都是蓋在上面的 modal，關閉後回到原處。專案名稱在工具列上就能改，Enter 或離開時寫入，Esc 放棄；與設定頁的名稱欄是同一個值。

### 1.1 整頁容器

| 規則 | 做法 |
|---|---|
| 容器 | drawer 就是整頁容器，工具列放在 `drawer-content` 裡 |
| 高度 | 等於視窗，只有清單捲動 |
| 視窗寬度 | 見 1.7 |
| 圖示 | Lucide 線條圖示 |
| 提示、標籤 | 實心，不用 soft |
| 開關按鈕 | 開啟時 `btn-primary`，以 `aria-pressed` 標出 |
| 收起鈕 | 開關按鈕，圖示畫出收起的部分 |

圖示一律用 Lucide 的線條圖示，不用字元，放在文字旁而不在裡面；只有圖示的按鈕用 `btn-square`，以 aria-label 命名。按鈕文字不折行。soft 的字在亮色底看不清。btn-active 只比原色深一點，深色主題分不出開關，所以開啟的按鈕與 daisyUI 勾選的 btn 同樣用 primary。

### 1.2 Tooltip

| 規則 | 做法 |
|---|---|
| 共用一個 | 移上元素時才定位 |
| 放在哪裡 | 頁面，或開著的 modal |
| 說明文字 | 元素以 `data-tooltip` 寫出 |
| 方向 | 在右半邊時往左開 |

全頁只有一個 `tooltip tooltip-open`，放在元素所在的最外層。

側欄與 modal 會裁切超出的內容，daisyUI 的 tooltip 又畫在元素之內，所以不在每個元素各放一個。

### 1.3 通知

```
                    ┌ 會自動消失 ───────────────┐
                    │● 翻譯完成        [動作][×]│ ← 動作可省略
                    │  說明或名稱與數值         │
                    │▓▓▓▓▓▓▓▓▓░░░░░░░░░         │ ← 倒數條，6 秒
                    └───────────────────────────┘
                    ┌ 不會自動消失 ─────────────┐
                    │✕ 轉錄失敗              [×]│ ← 只有失敗
                    │  whisper-cli 結束…        │
                    └───────────────────────────┘ ← 新的在下
```

| 規則 | 做法 | 元件 |
|---|---|---|
| 卡片 | 色條與圖示標出種類 | alert |
| 會自動消失 | 倒數 6 秒，停留時暫停 | progress |
| 附動作 | 照常倒數 | btn |
| 不會自動消失 | 只有失敗 | — |
| 關閉 | 每則都有 ×，隨時可按 | btn |
| 堆疊 | 最多 5 則，移除最舊 | toast |
| 動畫 | 滑入淡入，淡出消失 | — |
| 存檔 | 只在附動作時發，見 1.5 | — |

卡片白底，成功綠、警告黃、失敗紅。堆疊不互相取代，前一則的提議不會被下一則蓋掉。附動作的（如「加入詞彙表」）也倒數，才不會越積越多；游標停在上面時暫停，來得及按。點卡片本身不會關閉。

### 1.4 快速鍵一覽

```
  ┌ 快速鍵 ──────────────────────────────────┐
  │ 任何時候                                 │
  │   復原                         [⌘] [Z]   │ ← 停留時 tooltip 說明何時有效
  │   取代                     [⌘] [⌥] [F]   │ ← 只列這個平台的按鍵
  │ 播放與時間軸                             │
  │ 編輯欄位中                               │
  │ 滑鼠                                     │
  │                                  [關閉]  │
  └──────────────────────────────────────────┘
```

| 部分 | 做法 | 元件 |
|---|---|---|
| 開啟 | 工具列 ⌨、⌘/Ctrl+/ | btn、快速鍵 |
| 不在打字時 | 也可以按 `?` | 快速鍵 |
| 按鍵 | 只列這個平台 | kbd |
| 每列 | tooltip 說明條件 | 1.2 的 tooltip |
| 有快速鍵的按鈕 | tooltip 接上按鍵 | 1.2 的 tooltip |
| 選單項目 | 右側列出按鍵 | kbd |

| 分組 | 何時有效 |
|---|---|
| 任何時候 | 焦點在哪都可以 |
| 播放與時間軸 | 不在欄位或鍵盤選到的控制項 |
| 編輯欄位中 | 焦點在欄位裡 |
| 滑鼠 | 點選、雙擊、拖動與滾輪 |

同一個鍵在不同地方作用不同，所以依何時有效分組。滑鼠點過的按鈕不接空白鍵。一覽只供查詢，不能改鍵。按鍵以 `ui/shortcuts.ts` 為準，一覽、tooltip 與選單都由它產生。

### 1.5 存檔提示

```
  ep01 ✓ 已存檔   譯文 [English ▾] …
       └──┬───┘
          寫入後淡入，1.5 秒後淡出
```

| 規則 | 做法 |
|---|---|
| 位置 | 標題列資源名稱之後 |
| 時機 | 每次寫入 |
| 連續寫入 | 重新計時，不疊加 |
| 窄視窗 | 由資源名稱讓出空間 |
| 報讀 | `role="status"` |
| 動畫 | 淡入淡出，少動態時不動 |

編輯每離開一格就寫入一次，逐則通知會堆在正在改的段落上，所以一般存檔只在這裡標出。存檔若附帶動作，例如新增說話者，仍發 1.3 的通知，才按得到。

### 1.6 開啟選單

```
  [開啟 ▾]
  ┌──────────────────────────┐
  │ 開啟目錄                 │
  │ 開啟 SRT                 │
  │ 最近的專案               │ ← 標題，沒有時隱藏
  │ 2026-09-24-lecture-part2 │ ← 停留時 tooltip 顯示路徑
  └──────────────────────────┘

```

| 規則 | 做法 | 元件 |
|---|---|---|
| 標題 | 與選項平鋪 | menu-title |
| 每項 | 專案名稱 | menu |
| 寬度 | `w-40` 到 `max-w-80` | dropdown |
| 超過上限 | 截斷 | — |
| 路徑 | 1.2 的 tooltip | tooltip |
| 目前的專案 | 不列出 | — |

目錄名稱常帶日期或集數，固定寬度會截掉，所以選單隨名稱變寬，上限約 20 個中文字。只列名稱，路徑放在 tooltip。目前開著的專案不必再開，所以不列出。

### 1.7 視窗寬度

#### 1.7.1 資源清單

```
  wide, landscape                 wide, portrait / narrow
  ┌──────┬──────────────────┐     ┌────────────────────────┐
  │ list │ [<] lecture ...  │     │ [=] lecture ...        │
  │      │ editor           │     │ editor, full width     │
  └──────┴──────────────────┘     └────────────────────────┘
   wide: [<] or Cmd/Ctrl+B docks or undocks the list
   narrow: [=] or Cmd/Ctrl+B lays the list over the editor
```

| 部分 | 寬視窗 | 窄視窗 | 元件 |
|---|---|---|---|
| 預設 | 橫放固定，直立不固定 | 不固定 | drawer |
| 按鈕 | 收起或固定 | 蓋上清單 | btn-square（1.1 開關按鈕） |
| ⌘/Ctrl+B | 同按鈕 | 同按鈕 | 快速鍵 |
| 記住 | 橫放、直立各一份 | — | — |
| 選了資源 | — | 收回清單 | drawer-toggle |

寬視窗指至少 1024px。直立是為了一次看更多段落，寬度留給編輯區，所以預設不固定；螢幕轉向時換成該方向記住的選擇。最小視窗 800px 扣掉清單只剩約 576px，所以窄視窗不固定。

#### 1.7.2 工具列按鈕

```
  編輯區 ≥ 1024px：[📂 開啟 ▾] [🎙 轉錄] [🌐 翻譯] [👥 辨識] [⤓ 匯出 ▾] [⚙ 設定] [⌨]
  編輯區 < 1024px：[📂▾] [🎙] [🌐] [👥] [⤓▾] [⚙] [⌨]   ← 停留時 tooltip 顯示名稱
```

| 部分 | 編輯區 ≥ 1024px | 編輯區 < 1024px | 元件 |
|---|---|---|---|
| 工具列按鈕 | 圖示與文字 | 只留圖示 | btn、tooltip |
| 標題列按鈕 | 圖示與文字 | 只留圖示 | btn、tooltip |
| 譯文標籤 | 顯示 | 隱藏，選單留著 | select |
| 任務進度 | 完整 | 摘要截斷 | dropdown |
| 預覽控制 | 一行 | 放不下就換行 | flex-wrap |

按鈕看的是編輯區本身的寬度（container query），不是視窗：清單收合後，800px 與 1024px 視窗的編輯區一樣寬。圖示按鈕仍以 aria-label 命名，名稱放進 1.2 的 tooltip。

```
  │ ▸ ep01       │  ← 目前資源：第一列名稱，
```

| 元素 | 內容 | 元件 |
|---|---|---|
| 標題 | 「資源」與重新載入 | menu-title、btn |
| 資源 | 名稱與標示兩列 | menu、tooltip |
| 譯文 | 已有的譯文語言代碼 | badge |
| 沒有字幕 | 只有媒體檔時標出，提醒可以轉錄 | status |
| 純字幕 | 沒有媒體檔時標出 | badge-outline |

| 項目間距 | 底色彼此不相連 | menu、gap |

側欄寬度固定，直立與窄視窗的清單由按鈕蓋上（1.7.1）；淺色主題的 base-200 與白底太接近，改用 base-300。目前資源以 `menu-active` 標出，全名以 1.2 節的 tooltip 顯示。任務進行中仍可切換資源，結果寫進開始任務的資源。

### 3.1 重新載入

| 時機 | 做法 |
|---|---|
| 按 ↻ 或 ⌘/Ctrl+R | 重新配對目錄，重讀目前資源 |
| 視窗取得焦點 | 清單或字幕有變才重新載入 |
| 任務在目前資源進行中 | 只重新配對清單 |
| 欄位輸入中 | 先寫入再重新載入 |

外部新增、刪除或改寫的檔案因此反映在清單。顯示中的譯文照舊；目前資源不在了就選第一個。字幕沒被別處改過時保留復原紀錄。

### 7.1 版本與更新

```
  版本與更新  版本 v0.1.0（a1b2c3d）[複製] ─▶ 剪貼簿、通知

  啟動 ─▶ 啟動時檢查更新？ ─否─▶ 不檢查
              │是
              ▼
  ┌ 通知 ──────────────────────┐       版本與更新
  │● 有新版本 v0.2.0 [更新][×] │       更新 [檢查更新] 有新版本 v0.2.0 [更新]
  └──────────────┬─────────────┘                                        │
                 └──────────────▶ 安裝（7.1.3）◀────────────────────────┘
```

| 部分 | 內容 | 元件 |
|---|---|---|
| 版本 | 名稱與 commit | list、btn |
| 檢查更新 | 檢查中顯示轉圈 | btn、loading |
| 狀態 | 最新版或新版名稱 | text、btn |
| 啟動時檢查 | 預設開 | toggle |
| 找到新版 | 附更新的通知 | alert、btn |

版本是列表的第一列，與更新的各列對齊。啟動時的檢查失敗不通知，只記在 log；按下檢查更新而失敗才通知。找到新版時，通知與這一區都能開始安裝，不會自行安裝。複製版本寫入 `Tsuzuri v0.1.0 (a1b2c3d)`，供回報問題；名稱見 7.1.1。

#### 7.1.1 版本的名稱

```
  Stable   Version v0.2.0 (a1b2c3d) [Copy] ─▶ Tsuzuri v0.2.0 (a1b2c3d)
  Preview  Version Build 20260928+12 (a1b2c3d) [Copy] ─▶ Tsuzuri Build 20260928+12 (a1b2c3d)
  Notice   A new preview is available (Build 20260928+12)
```

| 版本 | 名稱 | 來源 |
|---|---|---|
| 正式版 | `v` 加版號 | tag |
| 預覽版 | `Build` 日期加編號 | UTC 建置日、CI 編號 |

預覽版的版號只用來排序，不是會發布的版本，所以畫面、通知與複製都改用名稱，兩種版本一眼就分得開。

#### 7.1.2 更新通道

```
  更新通道 [穩定版 ▾] ─▶ 選預覽版 ─▶ 之後的檢查讀預覽版
     │ 預覽版執行中又選回穩定版
     ▼
  [立即退回穩定版] ─▶ 找到穩定版 ─▶ 安裝（7.1.3）
     └ 不按 ─▶ 下一個穩定版發布時照常更新
```

| 部分 | 內容 | 元件 |
|---|---|---|
| 更新通道 | 穩定版、預覽版 | select |
| 立即退回 | 預覽版且選穩定版 | btn |
| rpm 安裝 | 不顯示通道 | — |

沒選過時跟著執行中的版本，預覽版走預覽通道；切換只影響之後的檢查。預覽版的版號比目前的穩定版高，所以退回要明確按下，只有這一次允許安裝較舊的版本。rpm 把預覽版排在後續正式版之後，所以 rpm 安裝只有穩定版。

#### 7.1.3 安裝

```
  ┌ 正在更新到 v0.2.0 ────────────────┐
  │ 下載中 45%                        │
  │ ▓▓▓▓▓▓▓▓▓░░░░░░░░░░░              │ ← 大小未知時不定進度
```

| 切換目錄 | 重新啟動後生效 | btn、alert |
| 開啟目錄 | 以檔案管理員開啟 | btn |

選了新的目錄或切換除錯紀錄，但還沒生效時，各自顯示提示說明要重新啟動。

## 10 版本

```
  ┌ 版本 ep01 ───────────────────────────────────────────────────────┐
  │ 字幕 [原文 ▾]                                                    │
  │ 目前                                                             │
  │ [產出]   2026/9/25 上午10:45    [設為對照] [比較] [還原]          │
  │ [覆蓋前] 2026/9/24 下午6:02     [設為對照] [比較] [還原]          │
  │ ┌ 比較 ────────────────────────────────────────────────────────┐ │
  │ │ [2026/9/25 上午10:45 ▾] ↔ [目前 ▾]   ☑ 只看差異  [↑] [↓]      │ │
  │ │ 00:00:03 資料不上傳        資料不[會]上傳              [↺]   │ │ ← 字元層級標記
  │ │ 00:00:06 本機運算          本機運算（時間改過）        [↺]   │ │
  │ │ 00:00:08 嗯……              —                           [↺]   │ │ ← 只有一邊有
  │ └──────────────────────────────────────────────────────────────┘ │
  └──────────────────────────────────────────────────────────────────┘
```

| 元素 | 內容 | 元件 |
|---|---|---|
| 字幕 | 原文或每種譯文 | select |

備份檔名用 UTC 時間，畫面換成本機時間。還原本身也會留下備份，所以隨時可以還原回來。

### 10.1 備份與還原

| 元素 | 內容 | 元件 |
|---|---|---|
| 備份清單 | 新的在上，標出種類 | list、badge |
| 設為對照 | 讓編輯畫面比較這份 | btn |
| 還原 | 先備份目前再取代 | btn |

清單列出 `.tsuzuri/history/` 裡這個字幕的備份，種類是產出或覆蓋前。設為對照會改變 4.6 的比較對象並關閉 modal；還原後關閉 modal 並通知。

### 10.2 比較

| 元素 | 內容 | 元件 |
|---|---|---|
| 比較 | 並排兩個版本 | table、select |
| 只看差異 | 隱藏相同的列 | checkbox |
| 上一個、下一個 | 捲到前後相異的列 | btn |
| 單句還原 | 不同的列有 ↺ | btn |

兩個版本依時間重疊對齊，兩邊都可選備份或「目前」；相異的列標色，文字改過時再標出增刪字元。右邊是「目前」時才有 ↺，以左邊的備份還原那一列。
