# Tsuzuri 介面設計

這份文件記錄各畫面的配置，介面的改動先改這裡再實作。畫面背後的意圖與資料見 `docs/design.md` 第 2、11 章。元件與配色以 daisyUI 為基底，表中「元件」欄寫 daisyUI 元件名稱。

## 1 骨架

```
  ┌──────────────┬──────────────────────────────────────────────┐
  │ 資源清單     │ lecture   [開啟 ▾] [轉錄] [翻譯] [匯出 ▾] [設定] │
  │ （第 3 節）  ├──────────────────────────────────────────────┤
  │              │ 字幕編輯（第 4 節）                          │
  │              │   只有段落清單會捲動                         │
  └──────────────┴──────────────────────────────────────────────┘
```

| 區域 | 內容 | 元件 |
|---|---|---|
| 工具列 | 專案名稱與專案層級的動作 | navbar |
| 開啟 ▾ | 開啟目錄、開啟 SRT、最近的專案 | dropdown、menu |
| 轉錄、翻譯 | 開啟第 5、6 節的任務；目前資源不能開始時停用 | btn |
| 匯出 ▾ | 見第 8 節 | dropdown、menu |
| 設定 | 開啟第 7 節的設定 | btn |
| 整頁 | 左側資源清單佔滿視窗高度；右側是工具列與字幕編輯 | drawer（`drawer-open`） |

字幕編輯是唯一的主畫面，任務與設定都是蓋在上面的 modal，關閉後回到原處。

側欄與 modal 會裁切超出的內容，daisyUI 的 tooltip 又畫在元素之內，所以全頁共用一個 `tooltip tooltip-open`，放在元素所在的最外層（頁面或開著的 modal），滑鼠移上元素時才定位到它旁邊。元素以 `data-tooltip` 寫出說明文字。drawer 就是整頁容器，工具列放在 `drawer-content` 裡，整頁高度等於視窗，只有段落清單捲動。按鈕文字不折行，窄的時候由專案名稱讓出空間。

## 2 起始畫面

```
  ┌─────────────────────────────────────────────────────────────┐
  │ Tsuzuri                                                     │
  ├─────────────────────────────────────────────────────────────┤
  │              [開啟目錄]   [開啟 SRT]                        │
  │                                                             │
  │   最近的專案                                                │
  │   lecture      ~/Videos/lecture          2026-09-24         │
  │   interview    ~/Documents/interview     2026-09-20         │
  └─────────────────────────────────────────────────────────────┘
```

| 元素 | 動作 | 元件 |
|---|---|---|
| 開啟目錄 | 選擇目錄，當成專案開啟 | hero、btn-primary |
| 開啟 SRT | 選擇 SRT 後開啟所在目錄，選取該資源 | btn |
| 最近的專案 | 點一下開啟；顯示名稱、路徑與開啟時間 | list |

沒有開啟專案時顯示這個畫面。

## 3 資源清單

```
  ┌──────────────┐
  │ ▸ ep01       │  ← 目前資源：第一列名稱，
  │   en ja      │     第二列字幕狀態與譯文
  │   ep02       │
  │   ●          │  ← 只有媒體檔，還沒有字幕
  │   ep03-a-ver │  ← 名稱最多兩行，
  │   y-long-na… │     之後截斷，停留時顯示全名
  │   ep04       │  ← 沒有標示時只有一列
  │ ──────────── │
  │ 詞彙表 12 筆 │  ← 點一下開啟第 9 節；沒有時顯示「建立詞彙表」
  └──────────────┘
```

| 元素 | 內容 | 元件 |
|---|---|---|
| 資源 | 雙列：第一列名稱，最多兩行後截斷，全名在 tooltip；第二列是標示，沒有時只有一列；點一下成為目前資源 | menu、`menu-active`、tooltip |
| 譯文 | 已有的譯文語言代碼 | badge |
| 沒有字幕 | 只有媒體檔時標出，提醒可以轉錄 | status |
| 詞彙表 | `glossary.csv` 的筆數；點一下開啟第 9 節 | menu |

側欄寬度固定，不擠壓編輯區；名稱獨佔一列，長檔名也看得到大部分。全名的 tooltip 依第 1 節的做法，不被側欄裁切。任務進行中仍可切換資源，結果照樣寫進開始任務的那個資源。

## 4 字幕編輯

```
  ┌──────────────────────────────────────────────┐
  │ ep01                       譯文 [English ▾]  │
  │ 翻譯  ████████░░░░  132 / 210                │  ← 任務進行中才出現
  ├──────────────────────────────────────────────┤
  │ 00:00:01.000 → 00:00:03.500  今天我們來談隱私 │
  │                              Today we talk……  │
  │ 00:00:03.500 → 00:00:06.000  資料不上傳……     │
  │                              （尚未翻譯）     │
  └──────────────────────────────────────────────┘
```

| 區域 | 內容 | 元件 |
|---|---|---|
| 標題 | 目前資源名稱；譯文語言選單列出已有的譯文與「無」 | select |
| 進度 | 目前 Phase、百分比或第 N / 共 M；完成後顯示各 Phase 耗時 | progress |
| 段落清單 | 每段一列：左欄時間，右欄原文與譯文上下疊，可直接編輯 | list、textarea |

段落隨任務逐步出現。改動在離開欄位時寫回檔案；檔案已在外部改過時，清單換成檔案的內容，進度區提示這次的修改沒有寫入。只有媒體檔的資源顯示空清單與轉錄提示。

## 5 轉錄任務

```
  ┌ 轉錄 ep02 ───────────────────────────────┐
  │ 語言  繁體中文（主語言，在設定修改）      │
  │ 模型  Breeze-ASR-25                      │
  │ [✓] 完成後翻譯                           │
  │ ┌ 翻譯 ────────────────────────────────┐ │  ← 勾選後才出現
  │ │ 第 6 節的譯成、詞彙表與選項          │ │
  │ └──────────────────────────────────────┘ │
  │ ⚠ ep02.srt 已存在，開始後會覆蓋          │  ← 已有字幕時才出現
  │                      [取消] [覆蓋並開始] │
  └──────────────────────────────────────────┘
```

| 元素 | 內容 | 元件 |
|---|---|---|
| 語言、模型 | 唯讀，顯示專案主語言與目前的轉錄模型 | modal、fieldset |
| 完成後翻譯 | 勾選後展開第 6 節的翻譯選項，轉錄完成後以這些選項翻譯 | checkbox、fieldset |
| 覆蓋提示 | 目前資源已有主語言字幕時出現，按鈕改為「覆蓋並開始」 | alert-warning |
| 開始 | 關閉 modal 並開始，進度出現在字幕編輯 | btn-primary |

## 6 翻譯任務

```
  ┌ 翻譯 ep01 ───────────────────────────────┐
  │ 來源  繁體中文（主語言）   譯成 [English ▾]│
  │ 詞彙表  glossary.csv（12 筆）            │
  │ [ ] 說話者標籤  [ ] 自我檢查             │
  │ [ ] 滾動摘要 [100] 字                    │
  │                          [取消] [開始]   │
  └──────────────────────────────────────────┘
```

| 元素 | 內容 | 元件 |
|---|---|---|
| 來源 | 唯讀，專案主語言 | modal、fieldset |
| 譯成 | 預設為專案上次的翻譯語言 | select |
| 詞彙表 | 唯讀，`glossary.csv` 與筆數，沒有時顯示「無」 | — |
| 選項 | 說話者標籤、自我檢查、滾動摘要與字數，預設取自設定 | checkbox、input |
| 開始 | 關閉 modal 並開始，譯文逐批出現 | btn-primary |

目前資源沒有主語言字幕時，「翻譯」停用。轉錄的 modal 用同一組選項，兩處的預設相同。

## 7 設定

```
  ┌ 設定 ─────────────────────────────────────────────────┐
  │ 專案      主語言 [繁體中文 ▾]  雙語順序 [原文在上 ▾] │  ← 有開啟專案時
  │ 元件      ffmpeg ✓ 內建  whisper ✓ 內建  llama ✓ 內建 │
  │ 模型      轉錄 Breeze-ASR-25  翻譯 Qwen3-4B           │
  │ 翻譯      每批 [8] 句  重試 [3] 次  參考前後 [2] 句    │
  │ 關於      授權與使用的元件                            │
  └───────────────────────────────────────────────────────┘
```

| 分組 | 內容 | 元件 |
|---|---|---|
| 專案 | 主語言、雙語順序，寫入 `tsuzuri.config.json` | select |
| 元件 | 各元件一列：名稱、來源、指定執行檔；已指定時可恢復預設值，改回偵測或內建的版本 | list |
| 模型 | 各 Model Slot 一列：名稱、檔案、選擇檔案 | list |
| 翻譯 | 每批句數、拆半前的重試次數、參考前後句數，最小為 1 | input |
| 關於 | Tsuzuri 與元件授權聲明 | — |

整個設定放在一個較寬的 modal，每個分組用 fieldset 包起來，組名當標題。

## 8 匯出選單

```
  [匯出 ▾]
    雙語 SRT
    另存原文
    另存譯文
```

| 選項 | 沒有譯文時 |
|---|---|
| 雙語 SRT | 停用，顯示為淡色且不能點 |
| 另存原文 | 可用 |
| 另存譯文 | 停用，顯示為淡色且不能點 |

存檔對話方塊預設在專案目錄，檔名帶語言代碼。格式與檔名見 `docs/design.md` 1.3 與 10.3。

## 9 詞彙表

```
  ┌ 詞彙表 glossary.csv ────────────────────────────────┐
  │ 繁體中文        English          日本語             │
  │ [蝙蝠俠     ]   [Batman     ]    [バットマン  ] [×] │
  │ [阿福       ]   [Alfred     ]    [            ] [×] │
  │ [+ 新增一列]                                        │
  │ ⚠ 儲存後改用語言代碼標頭                            │  ← 讀到 source,target 時
  │                                   [取消] [儲存]     │
  └─────────────────────────────────────────────────────┘
```

| 元素 | 內容 | 元件 |
|---|---|---|
| 表格 | 每種支援的語言一欄，每個詞一列，可直接編輯 | modal、table、input |
| 新增、刪除 | 表格下方新增一列；每列最後可以刪除 | btn |
| 標頭提示 | 讀到 `source,target` 時出現 | alert-warning |
| 儲存 | 寫回 `glossary.csv`，沒有時建立；關閉 modal。檔案讀不到時停用，避免空表蓋掉原檔 | btn-primary |

modal 用較寬的 `max-w-5xl`，表格太寬時水平捲動。格式見 `docs/design.md` 9.3。
