# Tsuzuri 介面設計

這份文件記錄各畫面的配置，介面的改動先改這裡再實作。畫面背後的意圖與資料見 `docs/design.md` 第 2、11 章。元件與配色以 daisyUI 為基底，表中「元件」欄寫 daisyUI 元件名稱。

## 1 骨架

```
  ┌──────────────┬──────────────────────────────────────────────┐
  │ 資源清單     │ lecture   [開啟 ▾] [轉錄] [翻譯] [匯出 ▾] [設定] │
  │ （第 3 節）  ├──────────────────────────────────────────────┤
  │              │ 字幕編輯（第 4 節）                          │
  │              │   只有段落清單會捲動                         │
  └──────────────┴──────────────────────────────────────────────┘
```

| 區域 | 內容 | 元件 |
|---|---|---|
| 工具列 | 專案名稱與專案層級的動作 | navbar |
| 開啟 ▾ | 開啟目錄、開啟 SRT、最近的專案 | dropdown、menu |
| 轉錄、翻譯 | 開啟第 5、6 節的任務；目前資源不能開始時停用 | btn |
| 匯出 ▾ | 見第 8 節 | dropdown、menu |
| 設定 | 開啟第 7 節的設定 | btn |
| 整頁 | 左側資源清單佔滿視窗高度；右側是工具列與字幕編輯 | drawer（`drawer-open`） |
| 通知 | 右下角堆疊，一件事一則：轉錄完成、翻譯完成、失敗、編輯已存檔或沒有寫入；見 1.3 | toast、alert |

字幕編輯是唯一的主畫面，任務與設定都是蓋在上面的 modal，關閉後回到原處。

### 1.1 整頁容器

| 規則 | 做法 |
|---|---|
| 容器 | drawer 就是整頁容器，工具列放在 `drawer-content` 裡 |
| 高度 | 整頁高度等於視窗，只有段落清單捲動 |
| 窄視窗 | 按鈕文字不折行，由專案名稱讓出空間 |
| 圖示 | 一律用 Lucide 的線條圖示，不用字元；放在翻譯文字旁邊而不在裡面；只有圖示的按鈕用 `btn-square`，以 aria-label 命名 |

### 1.2 Tooltip

| 規則 | 做法 |
|---|---|
| 共用一個 | 全頁只有一個 `tooltip tooltip-open`，滑鼠移上元素時才定位到它旁邊 |
| 放在哪裡 | 元素所在的最外層：頁面，或開著的 modal |
| 說明文字 | 元素以 `data-tooltip` 寫出 |
| 方向 | 元素在視窗右半邊時開在左側，否則開在右側 |

側欄與 modal 會裁切超出的內容，daisyUI 的 tooltip 又畫在元素之內，所以不在每個元素各放一個。

### 1.3 通知

```
                    ┌ 會自動消失 ───────────────┐
                    │● 已存檔                   │
                    │  說明或名稱與數值          │
                    │▓▓▓▓▓▓▓▓▓░░░░░░░░░         │ ← 倒數條，6 秒
                    └───────────────────────────┘
                    ┌ 不會自動消失 ─────────────┐
                    │✕ 轉錄失敗       [動作] [×]│ ← 失敗，或附動作
                    │  whisper-cli 結束…        │
                    └───────────────────────────┘ ← 新的在下
```

| 規則 | 做法 | 元件 |
|---|---|---|
| 卡片 | 白底，左側色條與圖示標出種類（成功綠、警告黃、失敗紅），粗體標題下是一句說明，或名稱與數值的條列 | alert |
| 會自動消失 | 成功與警告；底部倒數條，6 秒後消失，滑鼠停留或焦點在內時暫停 | progress |
| 不會自動消失 | 失敗與附動作的，例如新說話者的「加入詞彙表」；右側 × 關閉，點卡片本身不關閉 | btn |
| 堆疊 | 每則都保留，不互相取代；最多 5 則，超過時先移除最舊、會自動消失的 | toast |
| 動畫 | 從右側滑入並淡入，消失時淡出；系統要求減少動態時不播放 | — |

一次連續編輯會產生多則「已存檔」，堆疊讓前一則的提議不會被下一則蓋掉。倒數條讓人看得出哪些會自己消失。

## 2 起始畫面

```
  ┌─────────────────────────────────────────────────────────────┐
  │ Tsuzuri                                                     │
  ├─────────────────────────────────────────────────────────────┤
  │              [開啟目錄]   [開啟 SRT]                        │
  │                                                             │
  │   最近的專案                                                │
  │   lecture      ~/Videos/lecture          2026-09-24         │
  │   interview    ~/Documents/interview     2026-09-20         │
  └─────────────────────────────────────────────────────────────┘
```

| 元素 | 動作 | 元件 |
|---|---|---|
| 開啟目錄 | 選擇目錄，當成專案開啟 | hero、btn-primary |
| 開啟 SRT | 選擇 SRT 後開啟所在目錄，選取該資源 | btn |
| 最近的專案 | 點一下開啟；顯示名稱、路徑與開啟時間 | list |

沒有開啟專案時顯示這個畫面。

## 3 資源清單

```
  ┌──────────────┐
  │ ▸ ep01       │  ← 目前資源：第一列名稱，
  │   en ja      │     第二列字幕狀態與譯文
  │   ep02       │
  │   ●          │  ← 只有媒體檔，還沒有字幕
  │   ep03-a-ver │  ← 名稱最多兩行，
  │   y-long-na… │     之後截斷，停留時顯示全名
  │   ep04       │  ← 沒有標示時只有一列
  │ ──────────── │
  │ 詞彙表 12 筆 │  ← 點一下開啟第 9 節；沒有時顯示「建立詞彙表」
  └──────────────┘
```

| 元素 | 內容 | 元件 |
|---|---|---|
| 資源 | 雙列：第一列名稱，最多兩行後截斷，全名在 tooltip；第二列是標示，沒有時只有一列；點一下成為目前資源 | menu、`menu-active`、tooltip |
| 譯文 | 已有的譯文語言代碼 | badge |
| 沒有字幕 | 只有媒體檔時標出，提醒可以轉錄 | status |
| 詞彙表 | `glossary.csv` 的筆數；點一下開啟第 9 節 | menu |
| 側欄 | base-300，比工具列深一階 | drawer |
| 項目間距 | 底色彼此不相連 | menu、gap |

側欄寬度固定，不擠壓編輯區；淺色主題的 base-200 與白底太接近，所以側欄用 base-300。名稱獨佔一列，長檔名也看得到大部分。全名以 1.2 節的 tooltip 顯示，不被側欄裁切。任務進行中仍可切換資源，結果照樣寫進開始任務的那個資源。

## 4 字幕編輯

```
  ┌────────────────────────────────────────────────────────────┐
  │ ep01  譯文 [English ▾] [對照 ▾] [版本] (◌ 轉錄 23% ▾) [▣] │  標題列
  ├──────────────┬─────────────────────────────────────────────┤
  │ 影片         │ 控制與目前段落                              │  預覽（4.1）
  ├──────────────┴─────────────────────────────────────────────┤
  │ 波形與段落區段（全寬）                                     │  時間軸（4.2）
  ├────────────────────────────────────────────────────────────┤
  │ 段落清單：一段一列，原文、譯文、參照上下疊（4.4）          │  只有這裡捲動
  └────────────────────────────────────────────────────────────┘
```

| 區域 | 內容 | 元件 |
|---|---|---|
| 標題 | 目前資源名稱；譯文語言選單列出已有譯文與「無」 | select |
| 對照 | 開啟 4.5 的選單 | dropdown |
| 版本 | 開啟第 10 節 | btn |
| 進度 | 任務中才出現，見 4.3 | dropdown |
| 預覽切換 | 顯示或收起預覽 | btn、swap |

段落隨任務逐步出現。只有媒體檔的資源顯示空清單與轉錄提示。預覽橫跨整個寬度，段落清單保持全寬，原文與譯文不被擠壓。

### 4.1 預覽

```
  ╭──────────────╮  ╭ card-border ────────────────────╮
  │ 影片 16:9    │  │ (▶)  01:02 / 24:10              │
  │              │  │ ─────────────────────────────── │
  │ 疊上這句     │  │ 目前段落 #2  00:02.960 → 06.040 │
  ╰──────────────╯  │ 這是一個錄影的測試              │
                    │ [空白鍵] 播這段                 │
                    ╰─────────────────────────────────╯
  ╭ 波形（全寬，4.2）──────────────── [−] 100% [+] ──╮
  ╰────────────────────────────────────────────────────╯
```

| 元素 | 內容 | 元件 |
|---|---|---|
| 底色 | 與編輯區同為 base-100 | — |
| 分區 | 卡片與波形框以邊框區隔 | card-border |
| 上排 | 視窗 30%，至少 160px | — |
| 影片 | 與卡片 2:3 分寬，圓角 | `rounded-box` |
| 疊字 | 正在播的那句原文 | — |
| 控制卡片 | 播放與時間 | card、btn-circle |
| 目前段落 | 編號、時間、原文與譯文 | badge、divider |
| 提示 | 空白鍵播這段 | kbd |
| 沒選段落 | 提示點一段選取 | — |
| 無法預覽 | 格式播不了時取代影片 | alert |
| 收起 | 標題列 [▣] 切換，記住選擇 | — |

灰色只留給左側資源清單，編輯區一律 base-100，層次靠邊框而不是底色。影片旁的卡片放播放與目前段落；音訊沒有影片欄，卡片佔滿上排。

### 4.2 時間軸

```
  ╭──────────────────────────────── [−] 100% [+] ╮
  │ ▁▃▇▅▂[░░░░ 1 ░░░░][▒▒ 2 ▒▒][████ 3 ████]▂▁▃ │
  │ 0:58        1:00        1:02        1:04     │
  ╰──────────────────────────────────────────────╯
```

| 元素 | 內容 | 元件 |
|---|---|---|
| 波形 | 全寬、高 112px，依最大音量放大 | wavesurfer.js |
| 波形框 | 圓角與邊框 | `rounded-box`、border |
| 取波形中 | 整列閃爍 | skeleton |
| 段落區段 | 半透明中性色深淺交錯 | Regions |
| 目前段落 | primary 淡色 | — |
| 點區段 | 選取該段 | — |
| 點空白處 | 跳到該時間 | — |
| 捲動 | 滾輪，不顯示捲軸 | — |
| 縮放按鈕 | 波形框右上，附倍率 | join、btn |
| 點倍率 | 回到 100% | — |
| 縮放手勢 | Ctrl、Alt 或 ⌘＋滾輪，捏合 | — |
| 刻度 | 依縮放調整間距 | Timeline |

滾輪捲動、Ctrl＋滾輪縮放是 Windows 的慣例，Alt＋滾輪則是 Subtitle Edit 的縮放方式，兩者都支援；按鈕的 tooltip 寫出這些組合鍵。區段只能點選；拖動邊界改時間是之後的功能。

### 4.3 進度

```
  (◌ 翻譯 63% ▾)                                ← 標題列，任務中才出現
  ┌──────────────────────────────────────────┐
  │ (✓準備元件)─(✓載入模型)─(✓找出…)─(◌翻譯) │  ← 點開才看
  │ 翻譯  ████████░░░░  63%  132 / 210        │
  └──────────────────────────────────────────┘
```

| 元素 | 內容 | 元件 |
|---|---|---|
| 徽章 | 轉圈、Phase 與百分比 | dropdown、loading |
| Phase | 依序列出 | steps |
| 已完成 | 上色並打勾 | `step-icon` |
| 進行中 | 上色並轉圈 | loading |
| 進度條 | 百分比 | progress |
| 說明 | 名稱、百分比、N / M | — |

任務只是暫時的狀態，所以只在標題列佔一個按鈕，細節點開才看。算不出百分比時徽章只寫 Phase，進度條不定；結束後徽章消失，完成或失敗以第 1 節的通知告知。

### 4.4 段落

```
  ☐ 00:00:01.000 → 00:00:03.500  A ▾  ⋮ │ 今天我們來談隱私           ← 原文
                                        │ Today we talk about privacy ← 顯示中的譯文
                                        │ ja  今日はプライバシー……   ← 參照，淡色唯讀
```

| 元素 | 內容 | 元件 |
|---|---|---|
| 左欄 | 勾選框、開始與結束時間、說話者、⋮ 選單 | checkbox、input + datalist、dropdown |
| 原文、譯文 | 直接編輯的欄位，外觀與 textarea 相同，只收純文字 | `contenteditable="plaintext-only"`、textarea 樣式 |
| 參照 | 4.5 勾選的每種語言一行，標上語言代碼，淡色唯讀 | — |
| 處理中 | 轉錄還沒寫出段落、切換資源讀取中時顯示幾列；翻譯中還沒譯到的譯文欄 | skeleton |

改動在離開欄位時寫回，並通知已存檔；檔案已在外部改過時換成檔案的內容，通知這次沒有寫入。

```
  ░░ 00:00:58  嗯……          ░░   ← 目前段落：primary 淡底色
     00:01:00  今天我們來談
  ▌  00:01:02  隱私這件事          ← 播放中：左側色條
```

| 動作 | 結果 |
|---|---|
| 點一列的任何地方 | 選取這段 |
| 空白鍵，停著 | 播這段，播完停 |
| 空白鍵，播放中 | 停止 |
| 整段播放 | 標出正在播的段落 |

選取與勾選不同，一次只有一段。焦點在欄位、輸入框或按鈕時，空白鍵照常輸入或按下。播放時選取不動，清單捲到正在播的段落；停止後色條消失，選取留在原處。

### 4.5 對照

```
  [對照 ▾]
  ┌ 原文 ────────────────┐
  │ ◉ 最新產出 9/25 14:02 │
  │ ○ 無                  │
  │   從版本選……          │
  ├ 譯文 en ─────────────┤
  │ ○ 最新產出 9/25 14:10 │
  │ ◉ 無                  │
  │   從版本選……          │
  ├ 參照 ────────────────┤
  │ ☑ 日本語  ☐ 한국어      │
  └──────────────────────┘
```

| 分組 | 內容 | 元件 |
|---|---|---|
| 原文 | 最新產出、目前選的備份、無；「從版本選……」開啟第 10 節 | menu-title、radio |
| 譯文 | 同原文，對象是顯示中的譯文；沒有顯示譯文時不出現 | menu-title、radio |
| 參照 | 顯示中譯文以外的每種譯文，可複選 | checkbox |

| 顯示譯文 | 原文比較 | 譯文比較 | 參照 | 呈現 |
|---|---|---|---|---|
| 無 | 無 | — | 0～n | 原文，參照疊在下方 |
| 無 | 備份 | — | 0～n | 原文欄標出差異 |
| L | 無 | 無 | 不含 L | 原文與 L 上下疊 |
| L | 備份 | 無 | 不含 L | 只有原文欄標出差異 |
| L | 無 | 備份 | 不含 L | 只有 L 欄標出差異 |
| L | 備份 | 備份 | 不含 L | 兩欄各自標出差異 |

備份很多時選單仍然很短，完整清單留在版本。換了顯示的譯文，譯文比較回到「無」；原文換成新的產出時，自動改比較它。

### 4.6 差異標記

```
  文 ↺ │ 資料不[會]上傳……          ← 欄位裡以底色標出新增的字
       │ 原：資料不上傳……           ← 備份的文字，刪掉的字畫刪除線
  文 ↺ │ Data never leaves…
  ┄ 已刪除（原文）00:00:08.000  嗯……  ↺
```

| 元素 | 內容 | 元件 |
|---|---|---|
| 標記 | 標在各自的欄位旁：文、時、新、分、合 | badge |
| 字元 | 新增的字以底色標在欄位裡；不支援時只有「原：」行 | CSS Custom Highlight |
| 原：行 | 文字改過時，欄位下方以淡色顯示備份文字，刪除的字加刪除線 | — |
| 已刪除 | 備份裡有、現在沒有的段落依時間插入一列，註明是原文或哪種譯文；兩邊都有時各一列 | — |
| 單句還原 | 標記與「已刪除」列的 ↺ 選單：還原這句；成對的另有只還原文字、只還原時間 | dropdown |

標記放在欄位旁，同時比較原文與譯文時，看得出是哪一邊變了。

### 4.7 段落操作與復原

| 動作 | 內容 | 元件 |
|---|---|---|
| 改時間 | 時間欄直接改 | input |
| ⋮ 選單 | 上方新增、下方新增、在游標處切割、刪除 | dropdown |
| 多段 | 勾選後清單上方出現「已選 N 段 [合併] [平移……] [取消]」；合併只在相鄰時可用，平移開小 modal 輸入毫秒 | checkbox、modal |
| 復原與重做 | ⌘/Ctrl+Z 復原，⌘/Ctrl+Shift+Z 或 Ctrl+Y 重做；游標在欄位裡只復原打字，其餘復原上一次對字幕的改動 | 快速鍵、編輯選單 |

說話者可挑選用過或詞彙表的名稱，或輸入新名稱；新名稱可從通知加入詞彙表。

## 5 轉錄任務

```
  ┌ 轉錄 ep02 ───────────────────────────────┐
  │ 語言  繁體中文（主語言，在設定修改）      │
  │ 模型  Breeze-ASR-25                      │
  │ [✓] 完成後翻譯                           │
  │ ┌ 翻譯 ────────────────────────────────┐ │  ← 勾選後才出現
  │ │ 第 6 節的譯成、詞彙表與選項          │ │
  │ └──────────────────────────────────────┘ │
  │ ⚠ ep02.srt 已存在，開始後會覆蓋          │  ← 已有字幕時才出現
  │                      [取消] [覆蓋並開始] │
  └──────────────────────────────────────────┘
```

| 元素 | 內容 | 元件 |
|---|---|---|
| 語言、模型 | 唯讀，顯示專案主語言與目前的轉錄模型 | modal、fieldset |
| 完成後翻譯 | 勾選後展開第 6 節的翻譯選項，轉錄完成後以這些選項翻譯 | checkbox、fieldset |
| 覆蓋提示 | 目前資源已有主語言字幕時出現，按鈕改為「覆蓋並開始」 | alert-warning |
| 開始 | 關閉 modal 並開始，進度出現在字幕編輯 | btn-primary |

## 6 翻譯任務

```
  ┌ 翻譯 ep01 ───────────────────────────────┐
  │ 來源  繁體中文（主語言）   譯成 [English ▾]│
  │ 詞彙表  glossary.csv（12 筆）            │
  │ [ ] 說話者標籤  [ ] 自我檢查             │
  │ [ ] 滾動摘要 [100] 字                    │
  │                          [取消] [開始]   │
  └──────────────────────────────────────────┘
```

| 元素 | 內容 | 元件 |
|---|---|---|
| 來源 | 唯讀，專案主語言 | modal、fieldset |
| 譯成 | 預設為專案上次的翻譯語言 | select |
| 詞彙表 | 唯讀，`glossary.csv` 與筆數，沒有時顯示「無」 | — |
| 選項 | 說話者標籤、自我檢查、滾動摘要與字數，預設取自設定 | checkbox、input |
| 開始 | 關閉 modal 並開始，譯文逐批出現 | btn-primary |

目前資源沒有主語言字幕時，「翻譯」停用。轉錄的 modal 用同一組選項，兩處的預設相同。

## 7 設定

```
  ┌ 設定 ─────────────────────────────────────────────────┐
  │ [專案] [整體]                                         │
  │ 主語言 ⓘ    [繁體中文 ▾]                              │  ← 專案頁
  │ 雙語順序 ⓘ  [原文在上 ▾]                              │
  │ 自動儲存雙語 ⓘ  [○]                                   │
  │ 覆蓋前備份 ⓘ  [○]                                     │
  │ ─────────────────────────────────────────────────── │
  │ 元件      ffmpeg ⓘ  內建  [指定] [還原預設值]          │  ← 整體頁
  │ 模型      轉錄 ⓘ  Breeze-ASR-25  [指定檔案]            │
  │ 翻譯      每批句數 ⓘ [8]  重試 ⓘ [3]  參考前後 ⓘ [2]    │
  │           常駐 llama-server ⓘ [●]  保留模型 ⓘ [0] 秒     │
  │ 日誌      ~/Library/Logs/…  [切換目錄] [開啟目錄]       │
  │ 關於      授權與使用的元件                            │
  └───────────────────────────────────────────────────────┘
```

| 分頁 | 內容 | 元件 |
|---|---|---|
| 專案 | 主語言、雙語順序、自動儲存雙語、覆蓋前備份，寫入 `tsuzuri.config.json`；沒有開啟專案時不出現 | tabs、select、toggle |
| 整體 | 元件、模型、翻譯與關於，存在軟體設定 | tabs、list、input |
| 說明 | 每個設定名稱旁的 ⓘ，停留時以 tooltip 說明用途與用法 | tooltip |

| 分組 | 內容 | 元件 |
|---|---|---|
| 元件 | 各元件一列：名稱、來源、指定執行檔；已指定時可還原預設值，改回偵測或內建的版本；偵測中顯示 skeleton | list、skeleton |
| 模型 | 各 Model Slot 一列：名稱、檔案、選擇檔案 | list |
| 翻譯 | 每批句數、拆半前的重試次數、參考前後句數，最小為 1 | input |
| 常駐 | 常駐 llama-server，預設開，關掉時每次翻譯才啟動；翻譯後保留模型的秒數，預設 0，常駐關掉時停用 | toggle、input |
| 日誌 | 目前寫入的目錄；[切換目錄] 選新的目錄，重新啟動後才改寫到那裡，選了而還沒生效時顯示提示；[開啟目錄] 以系統的檔案管理員開啟 | list、btn、alert |
| 關於 | Tsuzuri 與元件授權聲明 | — |

設定放在一個較寬的 modal，用 `tabs-border` 分成專案與整體兩頁，頁內每個分組用 fieldset 包起來，組名當標題。開啟專案後預設停在專案頁；沒有專案時只有整體頁。專案的設定只影響這個目錄，整體的設定影響每個專案。

## 9 詞彙表

```
  ┌ 詞彙表 glossary.csv ─────────────────────────────────────┐
  │ 繁體中文        English          日本語          說話者  │
  │ [蝙蝠俠     ]   [Batman     ]    [バットマン  ]  [ ] [×] │
  │ [阿福       ]   [Alfred     ]    [            ]  [✓] [×] │

  │ ⚠ 儲存後改用語言代碼標頭                                 │  ← 讀到 source,target 時
  │                                        [取消] [儲存]     │

```

| 元素 | 內容 | 元件 |
|---|---|---|
| 表格 | 每種支援的語言一欄，每個詞一列，可直接編輯 | modal、table、input |

| 新增、刪除 | 表格下方新增一列；每列最後可以刪除 | btn |
| 標頭提示 | 讀到 `source,target` 時出現 | alert-warning |
| 儲存 | 寫回 `glossary.csv`，沒有時建立；關閉 modal。檔案讀不到時停用，避免空表蓋掉原檔 | btn-primary |

modal 用較寬的 `max-w-5xl`，表格太寬時水平捲動。格式見 `docs/design.md` 9.3。

## 10 版本

```
  ┌ 版本 ep01 ───────────────────────────────────────────────────────┐
  │ 字幕 [原文 ▾]                                                    │
  │ 目前                                                             │
  │ [產出]   2026/9/25 上午10:45    [設為對照] [比較] [還原]          │
  │ [覆蓋前] 2026/9/24 下午6:02     [設為對照] [比較] [還原]          │
  │ ┌ 比較 ────────────────────────────────────────────────────────┐ │
  │ │ [2026/9/25 上午10:45 ▾] ↔ [目前 ▾]   ☑ 只看差異  [↑] [↓]      │ │
  │ │ 00:00:03 資料不上傳        資料不[會]上傳              [↺]   │ │ ← 字元層級標記
  │ │ 00:00:06 本機運算          本機運算（時間改過）        [↺]   │ │
  │ │ 00:00:08 嗯……              —                           [↺]   │ │ ← 只有一邊有
  │ └──────────────────────────────────────────────────────────────┘ │
  └──────────────────────────────────────────────────────────────────┘
```

| 元素 | 內容 | 元件 |
|---|---|---|
| 字幕 | 原文與目前資源的每種譯文 | select |
| 備份清單 | `.tsuzuri/history/` 裡這個字幕的備份，新的在上，以本機時間顯示，前面標出產出或覆蓋前 | list、badge |
| 設為對照 | 每份備份一個，讓字幕編輯（4.5）改比較這份，關閉 modal | btn |
| 比較 | 在 modal 下半部並排兩個版本，依時間重疊對齊；兩邊都可選備份或「目前」；相異的列標色，文字改過時再標出增刪字元 | table、select |
| 只看差異 | 勾選後隱藏相同的列 | checkbox |
| 上一個、下一個差異 | 捲到前後相異的列，並標為目前所在 | btn |
| 單句還原 | 右邊是「目前」時，不同的列有 ↺，以左邊備份還原這一列 | btn |
| 還原 | 先備份目前字幕，再以這份備份取代；關閉 modal 並通知 | btn |

備份檔名用 UTC 時間，畫面換成本機時間。還原本身也會留下備份，所以隨時可以還原回來。
