# Tsuzuri 介面設計

這份文件記錄各畫面的配置，介面的改動先改這裡再實作。畫面背後的意圖與資料見 `docs/design.md` 第 11 章。元件與配色以 daisyUI 為基底，表中「元件」欄寫 daisyUI 元件名稱。

## 1 骨架

```
  ┌─────────────────────────────────────────────────────────────┐
  │ 範例-0924.mp4 ▾                   [開啟 ▾] [匯出 ▾]         │
  ├─────────────────────────────────────────────────────────────┤
  │ [■轉錄]  [ 翻譯]  [ 編輯]                       [ 設定]     │
  ├─────────────────────────────────────────────────────────────┤
  │                                                             │
  │                  （目前分頁的畫面）                         │
  │                                                             │
  └─────────────────────────────────────────────────────────────┘
```

| 區域 | 內容 | 元件 |
|---|---|---|
| 工具列 | 專案名稱與開啟、匯出 | navbar |
| 專案名稱 ▾ | 目前的專案；選單裡可以補上媒體檔 | dropdown |
| 開啟 ▾ | 新專案、從 SRT 建立、最近的專案 | dropdown、menu |
| 匯出 ▾ | 見第 7 節 | dropdown、menu |
| 分頁 | 轉錄、翻譯、編輯、設定；在設定關掉的功能不顯示分頁 | tabs |

工具列放專案層級的動作，任何分頁都能使用。專案存檔（`docs/design.md` 2.2）上線前，不顯示專案名稱，開啟 ▾ 只有「從 SRT 建立」。

## 2 起始畫面

```
  ┌─────────────────────────────────────────────────────────────┐
  │ Tsuzuri                                                     │
  ├─────────────────────────────────────────────────────────────┤
  │   ＋ 新專案（選擇影片或音訊）                               │
  │   ＋ 從 SRT 建立                                            │
  │                                                             │
  │   最近的專案                                                │
  │   ─────────────────────────────────────────────             │
  │   範例-0924     轉錄 ✓ 翻譯 ✓        2026-09-24             │
  │   範例-0920     轉錄 ✓               2026-09-20             │
  └─────────────────────────────────────────────────────────────┘
```

| 元素 | 動作 |
|---|---|
| 新專案 | 選擇影片或音訊，建立後進入轉錄分頁 |
| 從 SRT 建立 | 選擇 SRT，建立後進入翻譯分頁 |
| 最近的專案 | 點一下開啟，並顯示已完成的模組與更新時間 |

沒有開啟專案時顯示這個畫面。

## 3 轉錄

```
  ┌─────────────────────────────────────────────────────────────┐
  │ 範例-0924.mp4 ▾                   [開啟 ▾] [匯出 ▾]         │
  ├─────────────────────────────────────────────────────────────┤
  │ [■轉錄]  [ 翻譯]  [ 編輯]                       [ 設定]     │
  ├─────────────────────────────────────────────────────────────┤
  │ 語言  [中文 ▾]      模型  Breeze-ASR-25                     │
  │ [ ] 說話者辨識                                              │
  │ [ ] 完成後翻譯      譯成  [English ▾]                       │
  │                                        [開始轉錄]           │
  ├─────────────────────────────────────────────────────────────┤
  │ 準備元件  ✓ 0.2s   轉檔  ✓ 3.1s   載入模型  ✓ 31s           │
  │ 轉錄      ████████░░░░  64%   00:12:40 / 00:19:50           │
  ├─────────────────────────────────────────────────────────────┤
  │ 00:12:31  資料不上傳是這次的前提                            │
  │ 00:12:36  所以全部在本機處理                                │
  └─────────────────────────────────────────────────────────────┘
```

| 區域 | 內容 | 元件 |
|---|---|---|
| 選項 | 語言、目前使用的模型、本次是否辨識說話者、是否接著翻譯 | fieldset、select、checkbox |
| 開始 | 主要動作，全頁只有一個 | btn-primary |
| 進度 | 每個 Phase 的狀態與耗時；有百分比時顯示進度條，沒有時顯示進行中 | progress |
| 即時段落 | whisper-cli 逐段印出的結果 | list |

模型在設定裡指定，這裡只顯示目前用哪一個。轉錄的結果成為目前專案，完成後切到編輯分頁。

## 4 翻譯

```
  ┌─────────────────────────────────────────────────────────────┐
  │ 範例-0924.mp4 ▾                   [開啟 ▾] [匯出 ▾]         │
  ├─────────────────────────────────────────────────────────────┤
  │ [ 轉錄]  [■翻譯]  [ 編輯]                       [ 設定]     │
  ├─────────────────────────────────────────────────────────────┤
  │ 來源  本專案的 Transcript ▾       譯成  [English ▾]         │
  │ 詞彙表  names.csv（12 筆）[指定] [清除]                     │
  │                                        [開始翻譯]           │
  ├─────────────────────────────────────────────────────────────┤
  │ 載入模型 ✓ 12s  找出被切開的句子 ✓ 8s  翻譯 ████░░ 132 / 210 │
  ├─────────────────────────────────────────────────────────────┤
  │ 00:00:01  今天我們來談隱私                                  │
  │           Today we talk about privacy                       │
  └─────────────────────────────────────────────────────────────┘
```

| 區域 | 內容 | 元件 |
|---|---|---|
| 選項 | 來源 Transcript、目標語言、翻譯詞彙表 | fieldset、select |
| 開始 | 主要動作，全頁只有一個 | btn-primary |
| 進度 | 每個 Phase 的狀態與耗時，翻譯顯示第 N / 共 M 段 | progress |
| 結果 | 原文與譯文上下並列 | list |

翻譯的對象是目前專案，沒有專案時不能開始。完成後切到編輯分頁。翻譯詞彙表跟著專案，沒有載入時顯示「未指定」，清除按鈕停用。

## 5 編輯

```
  ┌─────────────────────────────────────────────────────────────┐
  │ 範例-0924.mp4 ▾                   [開啟 ▾] [匯出 ▾]         │
  ├─────────────────────────────────────────────────────────────┤
  │ [ 轉錄]  [ 翻譯]  [■編輯]                       [ 設定]     │
  ├─────────────────────────────────────────────────────────────┤
  │ ┌────────────────────────┐  時間      說話者  原文 / 譯文   │
  │ │                        │  ▶00:01:00  CO   今天我們…       │
  │ │       影片預覽         │                   Today we…      │
  │ │  今天我們來談隱私      │   00:01:04  CL   好的，那…       │
  │ │                        │                   OK, so…        │
  │ └────────────────────────┘                                  │
  │  ◀◀  ▶  ▶▶   00:01:02 / 00:19:50                            │
  └─────────────────────────────────────────────────────────────┘
```

| 區域 | 內容 | 元件 |
|---|---|---|
| 預覽 | 影片與疊加的字幕；專案沒有媒體檔時不顯示 | — |
| 段落清單 | 每段一列：左欄時間與說話者，右欄原文與譯文上下疊；點一下跳到該時間 | list |
| 播放控制 | 播放、前後跳段、目前時間 | btn |

只有 SRT 的專案仍可編輯文字，補上媒體檔後才有預覽。

## 6 設定

```
  ┌─────────────────────────────────────────────────────────────┐
  │ 範例-0924.mp4 ▾                   [開啟 ▾] [匯出 ▾]         │
  ├─────────────────────────────────────────────────────────────┤
  │ [ 轉錄]  [ 翻譯]  [ 編輯]                       [■設定]     │
  ├─────────────────────────────────────────────────────────────┤
  │ 一般      介面語言 [使用系統語言 ▾]                         │
  │ 功能      [✓] 翻譯  [ ] 說話者辨識                          │
  │ 元件      ffmpeg ✓ 內建  whisper ✓ 內建  llama ✓ 內建       │
  │ 模型      轉錄 Breeze-ASR-25  翻譯 Qwen3-4B                 │
  │ 翻譯      context [4096]                                    │
  │ 關於      授權與使用的元件                                  │
  └─────────────────────────────────────────────────────────────┘
```

| 分組 | 內容 | 元件 |
|---|---|---|
| 一般 | 介面語言，預設使用系統語言 | select |
| 功能 | 要顯示哪些模組分頁 | checkbox |
| 元件 | 各元件一列：名稱、來源、指定執行檔 | list |
| 模型 | 各 Model Slot 一列：名稱、檔案、選擇檔案 | list |
| 翻譯 | context 大小 | input |
| 關於 | Tsuzuri 與元件授權聲明 | — |

每個分組用 fieldset 包起來，組名當標題。以上是軟體設定。有開啟專案時，另外顯示可以覆寫的專案設定。

## 7 匯出選單

```
  [匯出 ▾]
    原文 SRT
    譯文 SRT
    雙語 SRT
```

| 選項 | 沒有譯文時 |
|---|---|
| 原文 SRT | 可用 |
| 譯文 SRT | 停用，顯示為淡色且不能點 |
| 雙語 SRT | 停用，顯示為淡色且不能點 |

格式見 `docs/design.md` 1.3 與 10.3。
