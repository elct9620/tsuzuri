# Tsuzuri 介面設計

這份文件記錄各畫面的配置，介面的改動先改這裡再實作。畫面背後的意圖與資料見 `docs/design.md` 第 2、11 章。元件與配色以 daisyUI 為基底，表中「元件」欄寫 daisyUI 元件名稱。

## 1 骨架

```
  ┌──────────────┬──────────────────────────────────────────────┐
  │ 資源清單     │ lecture   [開啟 ▾] [轉錄] [翻譯] [匯出 ▾] [設定] │
  │ （第 3 節）  ├──────────────────────────────────────────────┤
  │              │ 字幕編輯（第 4 節）                          │
  │              │   只有段落清單會捲動                         │
  └──────────────┴──────────────────────────────────────────────┘
```

| 區域 | 內容 | 元件 |
|---|---|---|
| 工具列 | 專案名稱與專案層級的動作 | navbar |
| 開啟 ▾ | 開啟目錄、開啟 SRT、最近的專案 | dropdown、menu |
| 轉錄、翻譯 | 開啟第 5、6 節的任務 | btn |
| 匯出 ▾ | 見第 8 節 | dropdown、menu |
| 設定 | 開啟第 7 節的設定 | btn |
| 整頁 | 左清單，右工具列與編輯 | drawer（`drawer-open`） |
| 通知 | 右下角堆疊，見 1.3 | toast、alert |

字幕編輯是唯一的主畫面，任務與設定都是蓋在上面的 modal，關閉後回到原處。

### 1.1 整頁容器

| 規則 | 做法 |
|---|---|
| 容器 | drawer 就是整頁容器，工具列放在 `drawer-content` 裡 |
| 高度 | 等於視窗，只有清單捲動 |
| 窄視窗 | 由專案名稱讓出空間 |
| 圖示 | Lucide 線條圖示 |
| 提示、標籤 | 實心，不用 soft |

圖示一律用 Lucide 的線條圖示，不用字元，放在文字旁而不在裡面；只有圖示的按鈕用 `btn-square`，以 aria-label 命名。按鈕文字不折行。soft 的字在亮色底看不清。

### 1.2 Tooltip

| 規則 | 做法 |
|---|---|
| 共用一個 | 移上元素時才定位 |
| 放在哪裡 | 頁面，或開著的 modal |
| 說明文字 | 元素以 `data-tooltip` 寫出 |
| 方向 | 在右半邊時往左開 |

全頁只有一個 `tooltip tooltip-open`，放在元素所在的最外層。

側欄與 modal 會裁切超出的內容，daisyUI 的 tooltip 又畫在元素之內，所以不在每個元素各放一個。

### 1.3 通知

```
                    ┌ 會自動消失 ───────────────┐
                    │● 已存檔             [動作]│ ← 動作可省略
                    │  說明或名稱與數值          │
                    │▓▓▓▓▓▓▓▓▓░░░░░░░░░         │ ← 倒數條，6 秒
                    └───────────────────────────┘
                    ┌ 不會自動消失 ─────────────┐
                    │✕ 轉錄失敗              [×]│ ← 只有失敗
                    │  whisper-cli 結束…        │
                    └───────────────────────────┘ ← 新的在下
```

| 規則 | 做法 | 元件 |
|---|---|---|
| 卡片 | 色條與圖示標出種類 | alert |
| 會自動消失 | 倒數 6 秒，停留時暫停 | progress |
| 附動作 | 照常倒數 | btn |
| 不會自動消失 | 失敗；以 × 關閉 | btn |
| 堆疊 | 最多 5 則，移除最舊 | toast |
| 動畫 | 滑入淡入，淡出消失 | — |

卡片白底，成功綠、警告黃、失敗紅。堆疊不互相取代，前一則的提議不會被下一則蓋掉。附動作的（如「加入詞彙表」）也倒數，才不會越積越多；游標停在上面時暫停，來得及按。點卡片本身不會關閉。

## 3 資源清單

```
  ┌──────────────┐
  │ 資源       ↻ │  ← 重新載入（3.1）
  │ ▸ ep01       │  ← 目前資源：第一列名稱，
  │   en ja      │     第二列字幕狀態與譯文
  │   ep02       │
  │   ●          │  ← 只有媒體檔，還沒有字幕
  │   ep03-a-ver │  ← 名稱最多兩行，
  │   y-long-na… │     之後截斷，停留時顯示全名
  │   ep04       │  ← 沒有標示時只有一列
  │   notes      │
  │   字幕 en    │  ← 沒有媒體檔，只編輯字幕
  │ ──────────── │
  │ 詞彙表 12 筆 │  ← 點一下開啟第 9 節；沒有時顯示「建立詞彙表」
  └──────────────┘
```

| 元素 | 內容 | 元件 |
|---|---|---|
| 標題 | 「資源」與重新載入 | menu-title、btn |
| 資源 | 名稱與標示兩列 | menu、tooltip |
| 譯文 | 已有的譯文語言代碼 | badge |
| 沒有字幕 | 只有媒體檔時標出，提醒可以轉錄 | status |
| 純字幕 | 沒有媒體檔時標出 | badge-outline |
| 詞彙表 | 筆數，點開第 9 節 | menu |
| 側欄 | base-300 | drawer |
| 項目間距 | 底色彼此不相連 | menu、gap |

側欄寬度固定；淺色主題的 base-200 與白底太接近，改用 base-300。目前資源以 `menu-active` 標出，全名以 1.2 節的 tooltip 顯示。任務進行中仍可切換資源，結果寫進開始任務的資源。

### 3.1 重新載入

| 時機 | 做法 |
|---|---|
| 按 ↻ 或 ⌘/Ctrl+R | 重新配對目錄，重讀目前資源 |
| 視窗取得焦點 | 清單或字幕有變才重新載入 |
| 任務在目前資源進行中 | 只重新配對清單 |
| 欄位輸入中 | 先寫入再重新載入 |

外部新增、刪除或改寫的檔案因此反映在清單。顯示中的譯文照舊；目前資源不在了就選第一個。字幕沒被別處改過時保留復原紀錄。

## 4 字幕編輯

```
  ┌────────────────────────────────────────────────────────────┐
  │ ep01 譯文 [English ▾] [對照 ▾] [版本] [說話者] (◌ 23% ▾) [▣]│  標題列
  ├──────────────┬─────────────────────────────────────────────┤
  │ 影片         │ 控制與目前段落                              │  預覽（4.1）
  ├──────────────┴─────────────────────────────────────────────┤
  │ 波形與段落區段（全寬）                                     │  時間軸（4.2）
  ├────────────────────────────────────────────────────────────┤
  │ 段落清單：一段一列，原文、譯文、參照上下疊（4.4）          │  只有這裡捲動
  └────────────────────────────────────────────────────────────┘
```

| 區域 | 內容 | 元件 |
|---|---|---|
| 標題 | 資源名稱與譯文選單 | select |
| 對照 | 開啟 4.6 的選單 | dropdown |
| 版本 | 開啟第 10 節 | btn |
| 說話者 | 開啟 4.10 | btn |
| 進度 | 任務中才出現，見 4.3 | dropdown |
| 預覽切換 | 顯示或收起預覽 | btn、swap |

段落隨任務逐步出現。只有媒體檔的資源顯示空清單與轉錄提示。預覽橫跨整個寬度，段落清單保持全寬，原文與譯文不被擠壓。


| 區塊 | 卡片與波形框以邊框區隔 | card-border |

| 疊字 | 正在播的那句 | — |
| 疊字語言 | 原文、譯文或雙語 | join、btn |
| 疊字的譯文 | 標題列顯示中的 | — |
| 雙語順序 | 同雙語 SRT | — |
| 疊字底色 | 無、半透明、黑底，預設半透明 | dropdown |
| 沒有譯文 | 只能選原文 | — |

| 目前段落 | 編號、時間、原文與譯文 | badge、divider |
| 提示 | 空白鍵播這段 | kbd |
| 時間提示 | F11、F12 設開始與結束 | kbd |

灰色只留給左側資源清單，編輯區一律 base-100，層次靠邊框。疊字的譯文就是正在改的那份，雙語照專案設定的順序，看到的就是匯出的樣子；選擇記在這台電腦。音訊沒有影片欄與疊字選項，卡片佔滿上排。

### 4.3 進度

```
  (◌ 翻譯 63% ▾)                                ← 標題列，任務中才出現
  ┌──────────────────────────────────────────┐
  │ (✓準備元件)─(✓載入模型)─(✓找出…)─(◌翻譯) │  ← 點開才看
  │ 翻譯  ████████░░░░  63%  132 / 210        │
  │                                  [取消任務]│
  └──────────────────────────────────────────┘
```

| 元素 | 內容 | 元件 |
|---|---|---|
| 徽章 | 轉圈、Phase 與百分比 | dropdown、loading |
| Phase | 依序列出 | steps |
| 已完成 | 上色並打勾 | `step-icon` |
| 進行中 | 上色並轉圈 | loading |
| 進度條 | 百分比 | progress |
| 說明 | 名稱、百分比、N / M | — |
| 取消任務 | 停下元件，已出現的留著 | card-actions、btn |

任務只是暫時的狀態，所以只在標題列佔一個按鈕，細節點開才看。算不出百分比時徽章只寫 Phase，進度條不定；結束後徽章消失，完成、失敗或取消以第 1 節的通知告知。取消時已出現的段落與譯文留在畫面，不寫檔。

### 4.4 段落

```
  ☐ 00:00:01.000 → 00:00:03.500  A ▾  ⋮ │ 今天我們來談隱私           ← 原文
                                        │ Today we talk about privacy ← 顯示中的譯文
                                        │ ja  今日はプライバシー……   ← 參照，淡色唯讀
```

| 元素 | 內容 | 元件 |
|---|---|---|
| 左欄 | 勾選框、時間、說話者、⋮ 選單 | checkbox、dropdown |
| 原文、譯文 | 只收純文字的欄位 | `contenteditable="plaintext-only"`、textarea 樣式 |
| 參照 | 每種語言一行，唯讀 | — |
| 處理中 | 即將填入的位置 | skeleton |

改動在離開欄位時寫回，並通知已存檔；檔案已在外部改過時換成檔案的內容，通知這次沒有寫入。

```
  ░░ 00:00:58  嗯……          ░░   ← 目前段落：primary 淡底色
     00:01:00  今天我們來談
  ▌  00:01:02  隱私這件事          ← 播放中：左側色條
```

| 動作 | 結果 |
|---|---|
| 點一列的任何地方 | 設為目前段落 |
| 焦點進入列內 | 設為目前段落 |
| 空白鍵，停著 | 播這段，播完停 |
| 空白鍵，播放中 | 停止 |
| 整段播放 | 標出正在播的段落 |

目前段落與勾選不同，一次只有一段。焦點在欄位、輸入框或按鈕時，空白鍵照常輸入或按下。播放時清單捲到播放中的段落，目前段落留在原處。

### 4.5 Cursor

```
  ░░ 00:00:58  今天我們│來談      ← 焦點在欄位：游標閃爍
  ░░ 00:00:58  今天我們┃來談  ⋮   ← 開著選單：標為保留，游標靜止
  ░░ 00:00:58  今天[我們]來談     ← 選取一段文字：只標範圍
```

| 元素 | 外觀 | 元件 |
|---|---|---|
| 游標 | 2px，文字色 | 自己畫的元素 |
| 選取 | primary 30% 底色 | CSS Custom Highlight |
| 原生游標與選取 | 隱藏 | `caret-color`、`::selection` |
| 浮動選單 | 之後加入，貼著 Cursor | — |

只有目前段落會有 Cursor（design 10.7、10.8）。選單開著時游標停止閃爍、留在原處；進入另一段、點時間軸或欄位被鎖住時消失。分割後游標移到後半段的開頭。

### 4.6 對照

```
  [對照 ▾]
  ┌ 原文 ────────────────┐
  │ ◉ 最新產出 9/25 14:02 │
  │ ○ 無                  │
  │   從版本選……          │
  ├ 譯文 en ─────────────┤
  │ ○ 最新產出 9/25 14:10 │
  │ ◉ 無                  │
  │   從版本選……          │
  ├ 參照 ────────────────┤
  │ ☑ 日本語  ☐ 한국어      │
  └──────────────────────┘
```

| 分組 | 內容 | 元件 |
|---|---|---|
| 原文 | 最新產出、選的備份、無 | menu-title、radio |
| 譯文 | 同原文，對象是顯示中的 | menu-title、radio |
| 參照 | 其他譯文，可複選 | checkbox |

| 顯示譯文 | 原文比較 | 譯文比較 | 參照 | 呈現 |
|---|---|---|---|---|
| 無 | 無 | — | 0～n | 原文，參照疊在下方 |
| 無 | 備份 | — | 0～n | 原文欄標出差異 |
| L | 無 | 無 | 不含 L | 原文與 L 上下疊 |
| L | 備份 | 無 | 不含 L | 只有原文欄標出差異 |
| L | 無 | 備份 | 不含 L | 只有 L 欄標出差異 |
| L | 備份 | 備份 | 不含 L | 兩欄各自標出差異 |

「從版本選……」開啟第 10 節，備份很多時選單仍然很短。沒有顯示譯文時，譯文那組不出現。換了顯示的譯文，譯文比較回到「無」；原文換成新的產出時，自動改比較它。

### 4.7 差異標記

```
  文 ↺ │ 資料不[會]上傳……          ← 欄位裡以底色標出新增的字
       │ 原：資料不上傳……           ← 備份的文字，刪掉的字畫刪除線
  文 ↺ │ Data never leaves…
  ┄ 已刪除（原文）00:00:08.000  嗯……  ↺
```

| 元素 | 內容 | 元件 |
|---|---|---|
| 標記 | 文、時、新、分、合 | badge |
| 字元 | 新增的字標底色 | CSS Custom Highlight |
| 原：行 | 淡色顯示備份文字 | — |
| 已刪除 | 依時間插入一列 | — |
| 單句還原 | ↺ 選單 | dropdown |

標記放在欄位旁，同時比較原文與譯文時，看得出是哪一邊變了。不支援 Highlight 時只剩「原：」行。已刪除的列註明是原文或哪種譯文；成對的列也可只還原文字或時間。

### 4.8 段落操作與復原

| 動作 | 內容 | 元件 |
|---|---|---|
| 改時間 | 時間欄直接改 | input |
| ⋮ 選單 | 新增、切割、刪除、重新翻譯 | dropdown |
| 游標處切割 | ⌘⌥/Ctrl+Alt+Enter | 快速鍵、⋮ 選單 |
| 多段 | 勾選後出現勾選工具列 | checkbox、modal |
| 復原與重做 | ⌘/Ctrl+Z、⌘/Ctrl+Shift+Z | 快速鍵、編輯選單 |

勾選工具列是「已選 N 段 [合併] [平移……] [說話者……] [重新翻譯] [取消]」；合併只在相鄰時可用，平移開小 modal 輸入毫秒。焦點在欄位裡時只復原打字，其餘復原上一次對字幕的改動；Ctrl+Y 也能重做。

重新翻譯譯成顯示中的譯文，沒有顯示譯文時停用；進度與取消同整份翻譯。

### 4.9 說話者選單

```
  [co ▾] ─┬────────────────┐
          │ [輸入新名稱…]  │  ← Enter 設定
          │ ✓ co           │
          │   cl           │  ← 用過與詞彙表的全部名稱
          │   小明         │
          │ ────────────── │
          │   清除說話者   │
          └────────────────┘
```

| 部分 | 做法 | 元件 |
|---|---|---|
| 按鈕 | 顯示目前的說話者 | btn |
| 選單 | 列出全部名稱 | card、menu |
| 新名稱 | 輸入後按 Enter | input |
| 清除 | 這段不再有說話者 | menu |

選單不依按鈕上的名稱篩選，名稱清單在打開時才建立，段落多也不拖慢畫面。新名稱可從通知加入詞彙表。

### 4.10 設定說話者

```
  ┌ 設定說話者 ──────────────────────────┐
  │ 範圍 (•) 勾選的 3 段                  │  ← 從勾選工具列打開時才有
  │      ( ) 全部段落                     │
  │      ( ) 沒有說話者的段落             │
  │      ( ) 說話者是 [co ▾] 的段落       │  ← 改名
  │ 設為 [小明            ]  留空則清除   │
  │      [co] [cl] [小明]                 │  ← 點一下填入
  │                       [取消] [套用]   │
  └───────────────────────────────────────┘
```

| 部分 | 做法 | 元件 |
|---|---|---|
| 範圍 | 四選一 | radio |
| 改名 | 選一個已有的名稱 | select |
| 設為 | 輸入或點名稱 | input、btn |
| 套用 | 一步復原 | btn-primary |

長的字幕逐段設定太慢。四種範圍都在 webview 算出段落，交給 Rust 一次寫入。

## 5 轉錄任務

```
  ┌ 轉錄 ep02 ───────────────────────────────┐
  │ 語言  繁體中文（主語言，在設定修改）      │
```

覆蓋提示依組合說明會覆蓋什麼：已有主語言字幕、勾選完成後翻譯且譯成的語言已有譯文，或兩者都有。有任何一項時按鈕改為「覆蓋並開始」。

## 7 設定

```
  ┌ 設定 ─────────────────────────────────────────────────┐
  │ [專案] [整體]                                         │
  │ 主語言 ⓘ    [繁體中文 ▾]                              │  ← 專案頁
  │ 雙語順序 ⓘ  [原文在上 ▾]                              │
  │ 自動儲存雙語 ⓘ  [○]                                   │
  │ 覆蓋前備份 ⓘ  [○]                                     │
  │ 轉錄      VAD ⓘ  [依整體設定 ▾]  …                      │
  │ 模型      轉錄 ⓘ  依整體設定  [指定檔案]               │
  │ ─────────────────────────────────────────────────── │
  │ 元件      ffmpeg ⓘ  內建  [指定] [還原預設值]          │  ← 整體頁
  │ 轉錄      VAD ⓘ [○]  抑制非語音 ⓘ [○]  延續上文 ⓘ [●]   │
  │ 模型      轉錄 ⓘ  Breeze-ASR-25  [指定檔案]            │
  │           VAD ⓘ  ggml-silero-v6.2.0.bin  [指定檔案]    │
  │ 翻譯      每批句數 ⓘ [8]  重試 ⓘ [3]  參考前後 ⓘ [2]    │
  │           常駐 llama-server ⓘ [●]  保留模型 ⓘ [0] 秒     │
  │ 日誌      ~/Library/Logs/…  [切換目錄] [開啟目錄]       │
  │ 關於      授權與使用的元件                            │
  └───────────────────────────────────────────────────────┘
```

| 分頁 | 內容 | 元件 |
|---|---|---|
| 專案 | 只影響這個目錄 | tabs、select、toggle |
| 整體 | 影響每個專案 | tabs、list、input |
| 說明 | 名稱旁 ⓘ 的 tooltip | tooltip |

設定放在較寬的 modal，以 `tabs-border` 分成專案與整體兩頁，每個分組用 fieldset 包起來，組名當標題。開啟專案後停在專案頁，沒有專案時只有整體頁。ⓘ 說明各設定的用途。

### 7.1 專案

| 設定 | 內容 | 元件 |
|---|---|---|
| 主語言 | 轉錄與翻譯的來源 | select |
| 雙語順序 | 原文或譯文在上 | select |
| 自動儲存雙語 | 寫回時一併寫出 | toggle |
| 覆蓋前備份 | 覆蓋前留一份 | toggle |
| 轉錄設定 | 依整體、開或關 | select |
| 專案模型 | 轉錄與翻譯 | list |

這一頁寫入專案目錄的 `tsuzuri.config.json`，沒有開啟專案時不出現。轉錄設定每項預設依整體設定。專案模型沒有指定時顯示依整體設定，指定後可改用整體設定。

### 7.2 元件與模型

| 分組 | 內容 | 元件 |
|---|---|---|
| 元件 | 名稱、來源、指定執行檔 | list、skeleton |
| 轉錄 | 轉錄設定 | toggle |
| 模型 | 各 Model Slot 的檔案 | list |
| 關於 | 授權聲明 | — |

元件已指定時可還原預設值，改回偵測到的或內建的版本；偵測中顯示 skeleton。模型每個 Model Slot 一列，列出名稱、檔案與選擇檔案。轉錄設定是各專案的預設值（design 7.4）。

### 7.3 翻譯

| 設定 | 內容 | 元件 |
|---|---|---|
| 分批 | 每批句數、重試、參考句數 | input |
| 常駐 | 常駐 llama-server | toggle |
| 保留模型 | 翻譯後保留的秒數 | input |

數值最小為 1。常駐預設開，關掉時每次翻譯才啟動 llama-server；保留模型預設 0 秒，常駐關掉時停用。

### 7.4 日誌

| 部分 | 內容 | 元件 |
|---|---|---|
| 目錄 | 目前寫入的目錄 | list |
| 切換目錄 | 重新啟動後生效 | btn、alert |
| 開啟目錄 | 以檔案管理員開啟 | btn |

選了新的目錄但還沒生效時，顯示提示說明要重新啟動。

## 10 版本

```
  ┌ 版本 ep01 ───────────────────────────────────────────────────────┐
  │ 字幕 [原文 ▾]                                                    │
  │ 目前                                                             │
  │ [產出]   2026/9/25 上午10:45    [設為對照] [比較] [還原]          │
  │ [覆蓋前] 2026/9/24 下午6:02     [設為對照] [比較] [還原]          │
  │ ┌ 比較 ────────────────────────────────────────────────────────┐ │
  │ │ [2026/9/25 上午10:45 ▾] ↔ [目前 ▾]   ☑ 只看差異  [↑] [↓]      │ │
  │ │ 00:00:03 資料不上傳        資料不[會]上傳              [↺]   │ │ ← 字元層級標記
  │ │ 00:00:06 本機運算          本機運算（時間改過）        [↺]   │ │
  │ │ 00:00:08 嗯……              —                           [↺]   │ │ ← 只有一邊有
  │ └──────────────────────────────────────────────────────────────┘ │
  └──────────────────────────────────────────────────────────────────┘
```

| 元素 | 內容 | 元件 |
|---|---|---|
| 字幕 | 原文或每種譯文 | select |

備份檔名用 UTC 時間，畫面換成本機時間。還原本身也會留下備份，所以隨時可以還原回來。

### 10.1 備份與還原

| 元素 | 內容 | 元件 |
|---|---|---|
| 備份清單 | 新的在上，標出種類 | list、badge |
| 設為對照 | 讓編輯畫面比較這份 | btn |
| 還原 | 先備份目前再取代 | btn |

清單列出 `.tsuzuri/history/` 裡這個字幕的備份，種類是產出或覆蓋前。設為對照會改變 4.6 的比較對象並關閉 modal；還原後關閉 modal 並通知。

### 10.2 比較

| 元素 | 內容 | 元件 |
|---|---|---|
| 比較 | 並排兩個版本 | table、select |
| 只看差異 | 隱藏相同的列 | checkbox |
| 上一個、下一個 | 捲到前後相異的列 | btn |
| 單句還原 | 不同的列有 ↺ | btn |

兩個版本依時間重疊對齊，兩邊都可選備份或「目前」；相異的列標色，文字改過時再標出增刪字元。右邊是「目前」時才有 ↺，以左邊的備份還原那一列。
